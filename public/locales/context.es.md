## Quick Reference / Referencia Rápida

### Gender / Género
- **Papagaya** = feminine (femenino)
- All adjectives → feminine endings (-a)

```json
✓ "Rara"      // feminine
✗ "Raro"      // masculine (WRONG)
```

### Verb Forms / Formas Verbales
- Action buttons → infinitive (infinitivo)

```json
✓ "Examinar"  // infinitive
✓ "Bloquear"  // infinitive
```

### Abbreviations / Abreviaturas
```json
"{n}m ago"  → "hace {n}min"
"{n}h ago"  → "hace {n}h"
"{n}d ago"  → "hace {n}d"
```

### Addressing Player / Dirigirse al Jugador
- Use informal **"tú"** (not "usted")
