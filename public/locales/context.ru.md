## Quick Reference / Краткая справка

### Gender / Род
- **Попугай** = masculine (мужской род)
- All adjectives → masculine endings (-ый, -ий)

```json
✓ "Редкий"     // masculine
✗ "Редкая"     // feminine (WRONG)
```

### Verb Forms / Формы глаголов
- Action buttons → infinitive (инфинитив)

```json
✓ "Исследовать"  // infinitive
✓ "Закрепить"    // infinitive
```

### Abbreviations / Сокращения
```json
"{n}m ago"  → "{n}мин назад"
"{n}h ago"  → "{n}ч назад"
"{n}d ago"  → "{n}д назад"
```

### Addressing Player / Обращение к игроку
- Use informal **"ты"** (not "вы")
