## Quick Reference / Référence Rapide

### Gender / Genre
- **Perroquet** = masculine (masculin)
- All adjectives → masculine endings

```json
✓ "Rare"       // masculine (same form)
✓ "Légendaire" // masculine (same form)
```

### Verb Forms / Formes Verbales
- Action buttons → infinitive (infinitif)

```json
✓ "Examiner"    // infinitive
✓ "Verrouiller" // infinitive
```

### Abbreviations / Abréviations
```json
"{n}m ago"  → "il y a {n}min"
"{n}h ago"  → "il y a {n}h"
"{n}d ago"  → "il y a {n}j"  // jours
```

### Addressing Player / S'adresser au Joueur
- Use informal **"tu"** or formal **"vous"** (recommend informal)
