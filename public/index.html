🦜 ChromaWing - Interactive Parrot

🧬 ChromaWing - Breeding Game

Playable prototype of a genetics breeding game. Breed parrots with different genetic traits, see real Mendelian inheritance in action, and watch offspring inherit colors from their parents. Each parrot displays its genotype and phenotype.

🔬 Genetics Explorer

Interactive genetics calculator that shows how different gene combinations affect parrot coloration. Select genotypes (RR, Rr, rr) for color genes and see the resulting phenotype in real-time. Includes preset buttons for common parrot types.

Complete breeding simulation game with collection management, multiple generations, and realistic genetics. Select two parent parrots, breed them using Mendelian inheritance, and build your parrot collection. Features dynamic visual rendering based on genotype and generation tracking.
