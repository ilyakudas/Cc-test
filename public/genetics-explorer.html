🧬 ChromaWing Body-Part RGB Genetics

Each body part has 13 genes (4 red, 4 green, 4 blue, 1 gradient). Count of dominant alleles determines color intensity!

🎯 How it works: Each body part has its own set of 13 genes (4 red, 4 green, 4 blue, 1 gradient). Click on gene buttons to toggle between dominant (colored) and recessive (white). The COUNT of dominant alleles matters, not position!
Color Examples: rrrr = 0% red, Rrrr = 25%, RRrr = 50%, RRRr = 75%, RRRR = 100%
Gradient: If gradient gene is dominant, genes 1-2 control start color, genes 3-4 control end color. Example: rrRR creates gradient from black to red.

📊 Genetics System Explained

Normal Distribution:

With 4 genes per color channel, there are different numbers of ways to get each count:

  • 0 dominant (rrrr): 1 way → 0% color
  • 1 dominant (Rrrr): 4 ways → 25% color
  • 2 dominant (RRrr): 6 ways → 50% color (most common!)
  • 3 dominant (RRRr): 4 ways → 75% color
  • 4 dominant (RRRR): 1 way → 100% color

This creates realistic variation: Most offspring will have medium colors (around 50%), with fewer pure/absent colors.

Prevents graying: Each body part has independent genes, so wings can be pure red while body is pure green!

Gradient Gene:

When the gradient gene is dominant, genes are split into two groups:

  • Genes 1-2: Control the start color (left side)
  • Genes 3-4: Control the end color (right side)

Example: Red genes rrRR creates a gradient from black (rr = 0%) to red (RR = 100%).
Another: Red RRrr creates a gradient from red (RR) to black (rr).
Complex: Red RrRR, Green ggGG, Blue bbbb = dark red → bright yellow-green gradient!
