💡 Usage in Game

  • Individual IDs: Each of 119 paths has unique ID (e.g., wing-blue-1, body-yellow-5)
  • Programmatic coloring: document.getElementById('wing-blue-1').setAttribute('fill', color)
  • Gradient effects: Apply color progression across feather groups
  • Pattern support: Can replace solid fills with SVG patterns for speckled/striped genotypes
  • Genetic calculation: Color intensity based on gene dominance (RR vs Rr vs rr)

Genetic Variations Possible:

  • Blue-and-Gold: No red (rr), yellow body (YY), blue wings (BB)
  • Green Parrot: No red (rr), yellow+blue mixing (YY BB)
